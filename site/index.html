--- layout: page title: Introduction --- The **Nabu compiler** is a polyglot compiler that compiles source code into Java bytecode so it can be executed on the Java Virtual Machine (JVM). Writing a compiler is a complex task that takes a lot of time and usually requires a lot of expertise about the JVM. The goal of the Nabu compiler is to make this easier: it is designed to be **extendable**, so you can add support for your own language without having to write a compiler from scratch. ## What can you do with Nabu? - **Compile the Nabu language** to JVM bytecode. Nabu is a programming language whose syntax is based on Java and Kotlin. - **Interoperate with Java.** Nabu and Java code can be mixed in a single project, and Nabu code can call Java code and vice versa. Java 20 is supported. - **Write DSLs.** The compiler supports domain-specific languages (DSLs) so you can write code that is more readable and maintainable for a specific domain. See [DSL support](/plugins/dsl-support/) for an example with JPA. - **Target multiple backends.** Beyond the standard ASM backend (JVM bytecode), experimental backends exist for the JDK ClassFile API and LLVM (native). - **Add your own language.** The compiler is extended via plugins. Provide a language parser that parses source code and builds an AST, and the compiler does the rest.
**Extendable by design.** The compiler defines extension points. Just provide a language parser, an element resolver, or a code transformer, and register it in a `plugin.xml` file.
## The simplest extension Because the compiler is built around plugins, adding a language is largely about providing a `LanguageParser`: ```java public class SimpleLanguageParser implements LanguageParser { private final FileObject.Kind SOURCE_KIND = new FileObject.Kind(".simple", true); @Override public FileObject.Kind getSourceKind() { return SOURCE_KIND; } @Override public CompilationUnit parse(final FileObject fileObject, final CompilerContext compilerContext) { // TODO: Implement parsing logic for .simple files return null; } } ``` ## Demo application A demo application is available at the [Nabu petstore](https://github.com/potjerodekool/nabu-petstore) repository, showing the compiler in action. ## Getting started To use Nabu and Java together in a Maven project, see the [Maven Plugin](/maven-plugin/) documentation. For IDE support, check out the [Nabu Idea](https://github.com/potjerodekool/nabu-idea) plugin for IntelliJ.
